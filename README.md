KinoCMS - Cinema Management System
A comprehensive web application for managing cinema operations and content.
Features: 
  - User Management System
  - User registration and authentication
  - Role-based access control
  - User profiles and preferences
  - Admin Dashboard
  - Content management for movies, news, promotions
  - User administration
  - Statistics and analytics
  - Cinema hall configuration
  - Content Management
  - Movie listings and schedules
  - News and promotional content
  - Image galleries
  - SEO optimization
  - Database Integration MySQL database backend
  - JPA/Hibernate ORM
  - Transaction management
  - Data validation

Technology Stack: 
  - Backend: Java 17, Spring Boot, Spring Data JPA, Spring MVC, Spring Security
  - Frontend: - Thymeleaf, Bootstrap, jQuery, HTML/CSS/JavaScript
  - Database: - MySQL
  - Development: Maven, Docker, Git
  - Deployment: Tomcat, Docker
 
 Setup & Installation: 
  1. Clone repository
  2. Configure application.properties
  3. Build with Maven
  4. Deploy WAR file
  or run Docker container
 Environment Requirements: - JDK 17 - Docker - MySQL 8+ - Maven 3.6+
